# খাবার ও স্বাস্থ্য: ওয়েবসাইট চালু করার নিয়ম

সম্পাদনায়: ফায়সাল জামান মনি

এই ফোল্ডারে পুরো অ্যাপ আছে, সঙ্গে Google বা ইমেল দিয়ে লগইনের ব্যবস্থা। কাজ তিন ভাগে:

1. Firebase-এ লগইন আর ডাটাবেস চালু করা
2. GitHub-এ ওয়েবসাইট তোলা
3. দুটো জোড়া লাগানো

সময় লাগবে আধা ঘণ্টার মতো। কম্পিউটার থেকে করলে সহজ হবে।

## ফাইলগুলো কী

| ফাইল | কী কাজ |
|---|---|
| `index.html` | পুরো অ্যাপ |
| `account.js` | লগইন আর অনলাইনে জমা রাখার কোড |
| `firebase-config.js` | আপনার Firebase প্রজেক্টের তথ্য (ধাপ ৫-এ বসাবেন) |
| `privacy.html` | গোপনীয়তা নীতি (হলুদ জায়গাগুলো পূরণ করবেন) |
| `firestore.rules` | ডাটাবেসের তালা: প্রত্যেকে শুধু নিজের তথ্য দেখবে |
| `manifest.webmanifest`, `sw.js` | ফোনে অ্যাপের মতো বসানো আর ইন্টারনেট ছাড়া খোলার ব্যবস্থা |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` | অ্যাপের আইকন |
| `README.md` | এই নির্দেশনা |

## ভাগ ১: Firebase

**ধাপ ১. প্রজেক্ট খুলুন।**
<https://console.firebase.google.com> এ নিজের Google অ্যাকাউন্টে ঢুকুন। এরপর:
- “Create a project” চাপুন।
- নাম দিন, যেমন `khabar-o-shastho`।
- Google Analytics লাগবে না, বন্ধ রাখতে পারেন।

**ধাপ ২. লগইন চালু করুন।**
বাঁ দিকের মেনু থেকে **Build → Authentication → Get started** খুলুন। তারপর **Sign-in method** অংশে:
- **Google**: Enable করুন, একটা support email বেছে নিন, Save দিন।
- **Email/Password**: Enable করুন, Save দিন। নিচের “Email link” চালু করার দরকার নেই।

**ধাপ ৩. ডাটাবেস বানান।**
**Build → Firestore Database → Create database** খুলুন।
- **Location**: ইউরোপের একটা জায়গা বেছে নিন, যেমন `eur3 (Europe)` বা `europe-west8 (Milan)`। এটা পরে আর বদলানো যায় না। ইউরোপের মানুষের স্বাস্থ্য-তথ্য ইউরোপে রাখাই নিরাপদ।
- **Production mode** বেছে নিন।

**ধাপ ৪. ডাটাবেসের তালা বসান।**
**Firestore Database → Rules** খুলুন। সেখানের সব লেখা মুছে `firestore.rules` ফাইলের পুরো লেখা বসান, তারপর **Publish** চাপুন।

**ধাপ ৫. ওয়েব অ্যাপ যোগ করুন।**
- **Project settings** খুলুন (ওপরে বাঁয়ে ⚙️ চিহ্ন)।
- **Your apps** থেকে **</>** (Web) চাপুন, একটা নাম দিন, তারপর Register করুন। Firebase Hosting লাগবে না।
- এরপর `firebaseConfig = { ... }` আকারে একটা লেখা দেখাবে। সেখান থেকে `apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId` আর `appId` এর মানগুলো `firebase-config.js` ফাইলের `PASTE_...` জায়গাগুলোতে বসিয়ে ফাইলটা সেভ করুন।

> এই কী-গুলো গোপন নয়। ওয়েবসাইটে সবাই দেখতে পারে, সেটাই নিয়ম। তথ্যের সুরক্ষা আসে ধাপ ৪-এর তালা থেকে।

## ভাগ ২: GitHub-এ ওয়েবসাইট

**ধাপ ৬. রিপোজিটরি বানান।**
<https://github.com> এ ঢুকুন (অ্যাকাউন্ট না থাকলে খুলে নিন)। এরপর:
- **New repository** চাপুন।
- নাম দিন, যেমন `khabar`।
- **Public** রাখুন। বিনামূল্যের ওয়েবসাইটের জন্য এটা দরকার। এখানে শুধু অ্যাপের কোড থাকবে, কারও ব্যক্তিগত তথ্য নয়।

**ধাপ ৭. ফাইল তুলুন।**
**Add file → Upload files** চাপুন। এই ফোল্ডারের সব ফাইল টেনে ছাড়ুন, তারপর **Commit changes** দিন।

**ধাপ ৮. ওয়েবসাইট চালু করুন।**
**Settings → Pages** খুলুন। **Source** থেকে “Deploy from a branch” বেছে নিন। এরপর **Branch** হিসেবে `main` আর `/ (root)` বেছে **Save** দিন।
এক-দুই মিনিট পরে ঠিকানা দেখাবে, যেমন `https://আপনার-নাম.github.io/khabar/`।

## ভাগ ৩: জোড়া লাগানো

**ধাপ ৯. ঠিকানাটা Firebase-কে জানান।**
Firebase-এ **Authentication → Settings → Authorized domains → Add domain** খুলে `আপনার-নাম.github.io` লিখুন। শুধু ডোমেইনটা লিখবেন, `https://` বা `/khabar` ছাড়া।
এটা না করলে Google লগইনে “unauthorized domain” লেখা আসবে।

**ধাপ ১০. গোপনীয়তা নীতি পূরণ করুন।**
`privacy.html` ফাইলের হলুদ জায়গাগুলোতে নিজের নাম, ইমেল, তারিখ আর ডাটাবেসের জায়গা (ধাপ ৩) লিখুন। তারপর GitHub-এ ফাইলটা আবার তুলুন।

**ধাপ ১১. পরীক্ষা করুন।**
- ওয়েবসাইট খুলে “আমি” স্ক্রিনে যান।
- “আমি রাজি” ঘরে টিক দিয়ে Google দিয়ে ঢুকুন।
- বয়স বা কোনো রোগ বদলান।
- অন্য ফোনে একই ঠিকানা খুলে একই অ্যাকাউন্টে ঢুকুন। একই তথ্য আসা উচিত।

## ফোনে অ্যাপের মতো বসানো

ওয়েবসাইট GitHub-এ তোলার পর এটা নিজে থেকেই কাজ করবে, আলাদা কিছু করতে হবে না।

- **Android (Chrome):** সাইট খুললে "আরো" পাতায় "📲 ফোনে অ্যাপের মতো বসান" কার্ড আসবে। "বসান" চাপলেই হোম স্ক্রিনে আইকন বসে যাবে। কার্ড না এলে Chrome-এর ⋮ মেনু থেকে "Add to Home screen" চাপুন।
- **iPhone (Safari):** নিচের শেয়ার বোতাম (□↑) চাপুন, তারপর "Add to Home Screen"।
- একবার খোলা হলে ইন্টারনেট ছাড়াও অ্যাপ খুলবে। তবে লগইন আর অনলাইনে জমা রাখার জন্য ইন্টারনেট লাগবে।
- নতুন সংস্করণ তুললে `sw.js` ফাইলের ওপরের দিকে `VERSION`-এর শেষ সংখ্যাটা এক বাড়িয়ে দিন, যেমন `-1` থেকে `-2`। তাহলে সবার ফোনে নতুনটা চলে আসবে।

## জেনে রাখুন

- **খরচ**: অল্প ব্যবহারে Firebase-এর বিনামূল্যের Spark প্ল্যানই যথেষ্ট, কার্ড লাগে না। বিনামূল্যের সীমা পেরোলে কাজ থেমে যায়, নিজে থেকে টাকা কাটে না। বর্তমান সীমা Firebase-এর Pricing পাতায় দেখে নিন।
- **কারা কী দেখতে পারে**: প্রত্যেকে অ্যাপে শুধু নিজের তথ্য দেখতে পারেন। আপনি প্রজেক্টের মালিক হিসেবে Firebase কনসোলে ডাটাবেস খুলতে পারবেন। গোপনীয়তা নীতিতে সেটা সৎভাবে লেখা আছে।
- **আইন**: রোগ, ধর্ম আর অ্যালার্জির তথ্য ইউরোপের আইনে (GDPR) “বিশেষ ধরনের” তথ্য। অ্যাপে এজন্য আছে:
  - স্পষ্ট সম্মতির টিক
  - তথ্য ডাউনলোডের বাটন
  - সব মুছে ফেলার বাটন
  
  তবুও সবার জন্য খোলার আগে একজন আইনজীবীকে দিয়ে দেখিয়ে নেওয়া ভালো।
- **লগইন ছাড়া**: অ্যাপ লগইন ছাড়াও চলে। তখন তথ্য শুধু সেই ফোনে থাকে।
- **বের হলে**: সেই ফোন থেকে তথ্য সরে যায়, আবার ঢুকলে ফিরে আসে। ভাগাভাগি করা ফোনের জন্য এটা নিরাপদ।
- **অ্যাপ হালনাগাদ**: নতুন `index.html` পেলে GitHub-এ একই নামে আবার তুলে দিন। লোকের তথ্য Firebase-এ থাকে, তাই কিছু হারাবে না।
